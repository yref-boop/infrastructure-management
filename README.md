# infrastructure-management

### module 1:
we are asked to simulate a basic communication system, that should be able to send bits utilizing pulses
this system should also be able to simulate the effect noise would have on it

this practical is divided in 3 steps
 - implement 2-PAM modulator, functional for any given bits, and represent the output wave

### module 2:
we are asked to design a data processing center, given specified characteristics:
- identify rack dimensions, distribute components & design cooling systems
- design ethernet connections & storage, network switch schema
- uninterruptible power supply system (batteries & controllers)
- security system for access
